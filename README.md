# Prompt Compression Challenge — Challenge 1

## Goal
Compress the provided request for adding CSV export to an existing React analytics table while retaining all functional constraints and implementation expectations.

## Files
- `optimized_prompt.txt` — standalone prompt to give an AI coding assistant.
- `original_prompt.txt` — transcribed source prompt used for the comparison.
- `documentation/` — Word documents with the prompt, counts, reduction calculation, and explanation.
- `one_slide_summary.pptx` — one-slide presentation for evaluation.
- `SOLUTION_NOTES.md` — approach, constraints, validation checklist, and limitations.

## Results
| Metric | Result |
|---|---:|
| Original characters | 878 |
| Original estimated tokens (characters ÷ 4) | 219.50 (~220) |
| Optimized characters | 612 |
| Optimized estimated tokens (characters ÷ 4) | 153.00 (~153) |
| Estimated reduction | 30.30% |

## Method
1. Identify the task and every explicit constraint.
2. Remove greetings, repetition, and conversational filler.
3. Group related requirements under concise headings.
4. Preserve the inspection, implementation, reporting, and verification workflow.
5. Recount characters and calculate estimated token reduction using the organizer's formula.

## Important
The counts are based on the source scenario transcribed from the supplied photo and the optimized prompt body. They are estimates using `characters ÷ 4`, not tokenizer measurements. If the official source text has any differences, update the source text and recalculate.
